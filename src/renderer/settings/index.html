Add a calendar by link

Paste a calendar link (iCal / .ics)
  1. Google Calendar (web): your calendar → Settings and sharing → Integrate calendar → copy Secret address in iCal format.
  2. Outlook / Fastmail / others: look for Publish or an iCal/ICS link.
  3. Paste it below — add as many calendars as you like.

Connect Apple iCloud

Connect with an app-specific password
  1. Open appleid.apple.com → Sign-In & Security → App-Specific Passwords → generate one.
  2. Enter your Apple ID and that password below.

Connect Microsoft Exchange

Connect to your company Exchange server
  1. Ask IT for the EWS address — usually https://mail.company.com/EWS/Exchange.asmx.
  2. Sign in with your Windows login, e.g. CORP\jane or jane@corp.com.
  3. The server must be reachable — from the office network or VPN.
